# 🛒 Amazon Clone

Welcome to my very first web development project! This repository contains a frontend clone of the Amazon.com homepage, built from scratch to practice and showcase my foundational web design skills.

## 🚀 Live Demo
Check out the live project here: [Amazon Clone on Vercel](https://amazon-clone-omega-tawny.vercel.app)

## 💻 Tech Stack
*   **HTML5:** For structuring the web page and its various product sections.
*   **CSS3:** For styling, layout structuring, and recreating the classic Amazon UI.
*   **Deployment:** Vercel

## ✨ About the Project
This project was created as a stepping stone into frontend development. By rebuilding a complex and recognizable layout like Amazon, I focused on mastering:
*   CSS Flexbox and positioning for building the navigation bar and product grids.
*   Structuring clean and readable HTML.
*   Managing CSS properties for images, spacing, and hover effects.
